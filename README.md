## 📖 About

Trial Chamber Finder locates trial chamber structures from the world seed, showing vault chest positions and the optimal breeze/spider route.

---

## ✨ Features
<a name="features"></a>

- **All Chambers Listed** — sorted by distance.
- **Vault Chest Coords** — trial key vault positions.
- **Spawner Room Map** — trial spawner layout per chamber.
- **Ominous Vault Marker** — ominous vault positions highlighted.
- **Map Markers** — pins on minimap.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
